Overview

MindSharp Challenges is a skill and puzzle game. No account registration is required — the Application can be used immediately upon download. The Service Provider is committed to minimizing data collection and being transparent about the limited data that is processed.

What Information Does the Application Collect?

1. Analytics Data (Optional — User-Controlled)

The Application integrates Unity Analytics to help the Service Provider understand how players interact with the game (e.g., which games are played most, session lengths, crash reports). This data is used solely to improve the Application's gameplay and stability.

This feature is opt-in. The Application provides an in-game setting that allows you to enable or disable analytics data sharing at any time. When you disable this setting, no analytics data will be sent.

When analytics is enabled, Unity may collect:

  • Device type and model
  • Operating system version
  • Mobile country and language
  • Session duration and in-game events (e.g., levels started/completed)
  • Application crash and error reports
  • A non-personally-identifiable device identifier

This data is aggregated and anonymized. Unity acts as a data processor on behalf of the Service Provider. Please review Unity's Privacy Policy for more information: https://unity.com/legal/privacy-policy

2. Photo Library / Gallery Access (Optional — Feature-Triggered)

Certain purchasable in-game customization items (such as custom background images or custom sliding puzzle images) allow you to select a photo from your device's gallery to personalize the game's visuals.

This access is triggered only when you choose to use such a customization feature. When triggered:

  • The Application will request permission to access your device's photo library via the operating system's standard native permission dialog (iOS or Android).
  • You may grant or deny this permission at any time. Denying permission will simply prevent the customization feature from working; all other features of the Application remain fully functional.
  • The selected image is copied to the Application's local storage on your device for display purposes.
  • The image is never uploaded, transmitted, or shared with the Service Provider or any third party. It remains entirely on your device.
  • iOS users: The permission prompt will display a reason message explaining why gallery access is needed. You can manage this permission at any time in your device Settings → Privacy → Photos.
  • Android users: The Application will request the relevant media access permission. You can manage this in your device Settings → Apps → MindSharp Challenges → Permissions.

3. Game Progress Data and Cloud Save

The Application stores game progress locally on your device, including game preferences, settings (such as your analytics opt-in/opt-out choice), purchased item states, gem balance, and high scores.

To allow your progress to be restored if you reinstall the Application or switch devices, the Application uses platform-provided cloud save services:

  • Android: Your game progress is automatically backed up to Google Play Games Services (Saved Games), a service provided by Google. This requires you to be signed in to your Google Play Games account. Google may associate the save data with your Google account identifier.
  • iOS: Your game progress is automatically backed up to iCloud Key-Value Storage, a service provided by Apple. This requires iCloud to be enabled on your device and uses your Apple ID.

The data uploaded to these cloud services consists exclusively of your in-game progress (game settings, scores, purchased item states, gem balance). It does not include your name, email address, photos, or any other personal content beyond the game data itself.

The Service Provider does not have direct access to this cloud-stored data. It is stored and managed entirely within your Google or Apple account infrastructure, and is subject to Google's and Apple's respective privacy policies.

If cloud save is unavailable (e.g., you are offline or not signed in to a platform account), the Application continues to function normally and stores data locally on your device only. Local data will be lost if you clear the Application's data or uninstall without an active cloud save.

4. Information the Application Does NOT Collect

  • No name or email address (there is no registration or account system within the Application itself)
  • No precise or approximate location data
  • No contacts, microphone, or camera data
  • No payment information (in-app purchases are handled entirely by Google Play Store and, where available, the Apple App Store)
  • No photos or personal files beyond what you explicitly select for in-game customization, which remains on your device only

GDPR-K / UK GDPR (European Economic Area & United Kingdom)
